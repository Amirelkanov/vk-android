# Магазин приложений. MVP 

## Epic 1: Базовая настройка проекта и архитектуры

**Цель:** Подготовить фундамент приложения, настроить DI, навигацию и базовые компоненты слоев

**Общая оценка:** `3д`

### Задачи:

1. **Инициализация проекта и настройка Gradle** `4ч`
   * Создание проекта, разбиение по базовым слоям _(Domain, Data, Presentation)_
   * Подключение базовых зависимостей для разработки и тестирования
2. **Внедрение зависимостей** `6ч`
   * Построение графа зависимостей для слоев Domain, Data и Presentation
   * Интеграция DI-фрейморка, внедрение базовых модулей
3. **Настройка базовой навигации** `4ч`
   * Реализация навигации для переходов между страницами
4. **Создание базовых классов архитектуры** `4ч`
   * Базовые интерфейсы для UseCase, базовые классы для ViewModel _(обработка ошибок, управление состоянием UI)_

## Epic 2: Список приложений

**Цель:** Реализовать получение и отображение списка приложений

**Общая оценка:** `5д`

### Задачи:

1. **Domain: Модель и UseCase списка** `6ч`
   * Создание сущности элемента списка приложений
   * Создание интерфейса репозитория для получения списка приложений
   * Реализация UseCase'ов, связанных с получением списка приложений
2. **Data: Data Sources и DTO** `6ч`
   * Создание DTO для сети / БД, написание мапперов между DTO и доменной сущностью
   * Реализация удаленного и/или локального источника данных
3. **Data: Реализация репозитория** `4ч`
   * Имплементация репозитория для получения списка приложений
   * Настройка логики обработки ошибок источника данных _(возможно, добавить логику какого-либо кэширования)_
4. **Presentation: ViewModel списка** `4ч`
   * Создание ViewModel для списка приложений, подключение UseCase'ов
5. **Presentation: Верстка слоя списка** `6ч`
   * Верстка элемента списка
   * Верстка экрана списка _(учесть, что список может быть очень длинным)_
6. **Presentation: Интеграция и обработка состояний** `4ч`
   * Связывание UI и ViewModel
   * Отрисовка лоадеров, заглушек при ошибке, pull-to-refresh
7. **Тестирование** `6ч`
   * Тестирование мапперов и репозитория, UseCase'ов списка приложений

## Epic 3: Карточка приложения

**Цель:** Реализовать экран детальной информации о выбранном приложении _(предполагается, что сервер отдает разную информацию для списка приложений и детальной информации)_

**Общая оценка:** `5д`

### Задачи:

1. **Domain: Модель и UseCase детальной информации** `6ч`
   * Создание сущности детальной информации
   * Создание интерфейса репозитория для получения детальной информации
   * Реализация UseCase для получения детальной информации
2. **Data: Data Sources и DTO** `6ч`
   * Создание DTO для сети / БД, написание мапперов между DTO и доменной сущностью
   * Реализация удаленного и/или локального источника данных
3. **Data: Реализация репозитория** `4ч`
   * Имплементация репозитория для получения деталей о приложении
   * Настройка логики обработки ошибок источника данных _(возможно, добавить логику какого-либо кэширования)_
3. **Presentation: ViewModel карточки** `4ч`
   * Создание ViewModel для карточки приложения
   * Обработка передачи параметров через навигацию и загрузка данных
4. **Presentation: UI карточки (Верстка)** `6ч`
   * Верстка экрана детальной информации _(шапка, описание, галерея скриншотов)_
5. **Presentation: Интеграция навигации** `4ч`
   * Настройка передачи аргументов _(например, App ID)_ из списка приложений в карточку приложений
   * Обработка edge-кейсов _(например, "Приложение не найдено")_
6. **Тестирование** `6ч`
   * Тестирование мапперов и репозитория, UseCase'ов детальной информации


## Epic 4: Установка и удаление приложений

**Цель:** Реализовать взаимодействие с системой для скачивания, установки и удаления приложений, а также отслеживание статуса

**Общая оценка:** `6д`

### Задачи:

1. **Domain: UseCases управления приложениями** `6ч`
   * Создание UseCase для установки/удаления приложений
   * Создание UseCase для отслеживания статуса приложения
2. **Data: Менеджер пакетов** `8ч`
   * Реализация логики взаимодействия с системным пакетным менеджером
   * Реализация логики инициации загрузки приложения и вызова системного интента установки/удаления
3. **Data: Отслеживание состояний** `8ч`
   * Реализация слушателя системных событий _(установка/удаление завершено)_
   * Маппинг системных состояний в доменные статусы
4. **Presentation: Подключение логики к ViewModel** `6ч`
   * Обновление ViewModel для вызова UseCase установки/удаления
   * Подписка на изменения статуса для обновления UI State в реальном времени
5. **Presentation: Обновление UI** `8ч`
   * Верстка динамической кнопки действий _(Скачать -> Установить -> Открыть / Удалить)_
   * Добавление прогресс-бара скачивания/установки на карточку приложения и в элементы списка
6. **Тестирование** `8ч`
   * Тестирование логики установки и удаления приложений
